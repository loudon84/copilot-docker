# 财务经营分析办公室（BI 智能问数）业务使用指南

本文面向财务、经营分析、管理层等业务人员，说明「能问什么、怎么问、结果怎么读」。  
部署与运维细节见同目录 [README.md](README.md)。

---

## 1. 这是什么

`bi-strategic-office`（财务经营分析办公室）是一个 **用自然语言查询财务经营数据** 的 AI 专家助手。

你可以像对分析师说话一样提问，例如：

- 「查询 2026Q2 各产品销售利润报表」
- 「只看毛利率低于 5% 的产品」
- 「按销售区域拆分」
- 「解释销售利润的计算口径」

系统会通过 **SQLBot** 按已配置的表、字段、术语与 SQL 示例取数，并给出表格与说明；**不会**自行编造数字，也 **不会** 执行任意 SQL 或改账。

### 与「资金/财务运营」专家的区别

| 场景 | 找谁 |
|------|------|
| 账户余额、账龄、回款、头寸、资金计划、付款运营 | `finance` 专家 |
| 经营取数、产品/客户/区域利润、同比环比、指标口径、管理分析报告 | **本专家（BI）** |

## 2. 问数是怎么工作的（业务视角）

业务人员不需要写 SQL。一次标准问数大致是：

```text
你的自然语言问题
    ↓
Hermes 判断需要问数，调用 finance-bi 工具
    ↓
SQLBot Adapter（登录、会话、安全检查）
    ↓
SQLBot 生成并执行只读 SQL
    ↓
返回表格 +（可选）摘要/图表 + 警告
    ↓
Hermes 做经营分析与报告（不改数字）
```

要点：

1. **数字只来自工具返回** —— 分析结论可以推断，但表格里的数不得被 AI 改写。
2. **只读** —— 不会过账、核销、付款、改库。
3. **表与口径在 SQLBot 配置** —— 新增指标/改字段说明，由数据/财务 IT 在 SQLBot 管理界面维护。
4. **明确编号必须保留** —— 问「凭证号 XXX」时，若系统无法在查询中保留该编号，会拒绝返回「随便前几行」数据。

## 3. 相关目录对业务意味着什么

| 区域 | 业务含义 |
|------|----------|
| SQLBot 工作空间 / 数据源 | **真正的语义与权限配置**：表、字段别名、关系、术语、SQL 示例、行列权限 |
| `plugins/hermes-sqlbot-adapter/` | **适配插件**：连接 SQLBot，做安全检查与结果整理 |
| `sqlbot-adapter/state/` | **会话映射**：记住「接着问」的上下文（不保存完整结果明细） |
| `workspace/exports/bi/` | **导出与报告附件** 落盘位置 |

业务人员通常 **不用直接改这些目录**；需要新增指标或改口径时，联系数据/财务 IT 更新 SQLBot 配置，并同步更新实施记录 `docs/sqlbot-example.md`。

## 4. 怎么问效果更好

1. **说清时间**：如 `2026Q2`、`本月`、`2026-04-01~2026-06-30`
2. **说清主体/客户/产品**：避免「全库随便看一眼」
3. **查明细时带编号或范围**：如 `凭证号 101IN26070199`、`客户 XXX 近 30 天明细`
4. **追问用「接着筛」**：如「只看毛利率低于 5%」「按区域拆分」
5. **换主题时说明**：或让助手重置问数上下文后再问新问题

---

## 5. 结果怎么读

助手回答通常包含：

- 时间口径 / 主体范围 / 币种 / 指标口径
- 表格（来自 SQLBot）
- 经营分析（事实与推断分开）
- 警告（如结果被截断、过滤需复核）

若提示「未保留过滤条件」或「明细缺少过滤」，请补充条件后重问，不要要求「先随便返回几行」。

---

## 6. 不能做什么

- 不能改账、过账、付款
- 不能让助手手写 SQL 直连数据库
- 不能要求输出 SQLBot 账号密码或内部 Token
- 不能把完整敏感明细写入长期记忆

---
