# Sale Workspace

This folder stores sale expert work outputs.

Recommended folders are inherited from workspace root:

- `/data/hermes/workspace/materials/sale`: raw customer files, RFQ, BOM, CRM exports
- `/data/hermes/workspace/references/sale`: extracted customer facts and meeting notes
- `/data/hermes/workspace/drafts/sale`: email drafts, call scripts, proposal drafts
- `/data/hermes/workspace/reports/sale`: deal assessments, account plans, pipeline reports
- `/data/hermes/workspace/exports/sale`: customer-facing final files after human review
- `/data/hermes/workspace/artifacts/sale`: dashboards, HTML forms, charts

Never store executable scripts or final binary exports in Obsidian.
Never store raw customer-sensitive files in Obsidian.
