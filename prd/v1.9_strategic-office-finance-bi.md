## 2. 背景

`copilot-docker` 已支持通过 `expert-templates`、`create-instance.sh` 和 `inject-expert.sh` 创建独立的 Writer、Finance、Sale 等 Hermes 实例。每个实例拥有独立的 `HERMES_HOME`、workspace、sessions、skills 和 memories。

现有 `finance` 专家主要处理：

* 账户余额
* 应收应付账龄
* 订单回款
* 现金头寸
* 资金日报
* 资金预测
* 财务运营问题

本项目新增一个独立专家：

```text
bi-strategic-office
```

负责：

* 财务经营数据查询
* BI 智能问数
* 产品、客户、区域利润分析
* 同比、环比和差异分析
* 财务指标口径解释
* 管理层分析报告

Hermes 已提供 Plugin、Tool、Skill、Hook、Profile 和 `delegate_task` 等扩展机制，本项目不得修改 Hermes Agent 核心循环。

---

## 3. 产品目标

完成以下结果：

1. 在 `copilot-docker` 中新增 `bi-strategic-office` 专家模板。
2. 可以通过现有脚本创建并启动独立实例。
3. 在实例内安装 `hermes-finance-bi-plugin`。
4. 插件直接连接只读 BI 数据库，不单独部署查询服务。
5. 用户可以使用自然语言查询财务经营数据。
6. 查询必须经过语义定义、SQL 校验、权限过滤和审计。
7. 支持基于上一轮结果继续筛选、下钻和分析。
8. 支持将查询结果导出为 CSV 或 XLSX。
9. 不影响现有 `writer`、`finance`、`sale` 专家实例。

## 7. 专家团队设计

`bi-strategic-office` 使用一个主 Agent，按需调用子 Agent。

### 7.1 BI Strategy Director

主角色，负责：

* 理解问题
* 选择查询或分析路径
* 判断指标是否存在歧义
* 调用工具
* 决定是否委派子任务
* 组织最终输出

### 7.2 BI Query Analyst

负责：

* 识别指标、维度、时间和过滤条件
* 查询数据
* 下钻和筛选
* 返回结构化数据集

### 7.3 Finance Performance Analyst

负责：

* 产品利润分析
* 客户贡献分析
* 区域经营分析
* 同比和环比
* 差异归因

### 7.4 Semantic Governance Specialist

负责：

* 指标定义
* 字段含义
* 时间口径
* 币种和汇率口径
* 数据更新时间

### 7.5 Data Quality Reviewer

负责：

* 检查主体、时间和币种范围
* 检查指标版本
* 检查异常值和空值
* 检查汇总与明细是否一致

这些角色使用 Hermes `delegate_task` 按需创建，不部署独立常驻实例。

## 8. 查询处理流程

用户问题不得直接转换为可执行 SQL。

标准流程：

```text
用户自然语言
    ↓
检索相关语义定义
    ↓
生成 SemanticQuery
    ↓
确定性编译 SQL
    ↓
SQL AST 校验
    ↓
权限条件注入
    ↓
查询成本检查
    ↓
只读数据库执行
    ↓
结果标准化
    ↓
Hermes 分析和说明
```

### 8.1 SemanticQuery

模型输出以下结构，不直接输出 SQL：

```json
{
  "dataset": "product_profit_daily",
  "metrics": [
    "net_sales_amount",
    "gross_profit_amount",
    "gross_margin"
  ],
  "dimensions": [
    "product_code",
    "product_name"
  ],
  "filters": [
    {
      "field": "posting_date",
      "operator": "gte",
      "value": "2026-04-01"
    },
    {
      "field": "posting_date",
      "operator": "lt",
      "value": "2026-07-01"
    }
  ],
  "order_by": [
    {
      "field": "gross_profit_amount",
      "direction": "desc"
    }
  ],
  "limit": 200
}
```

### 8.2 歧义处理

以下情况不得自行猜测：

* “利润”存在多个指标
* 未指定主体且没有默认主体
* 未指定币种且没有默认币种
* 时间字段存在多种定义
* 用户要求的维度不能用于目标指标
* 查询需要未登记的 JOIN

返回：

```json
{
  "status": "clarification_required",
  "questions": [
    "销售利润是指销售毛利还是经营利润？"
  ]
}
```

### FR-03 核心工具

#### `finance_bi_ask`

输入：

```json
{
  "question": "查询2026Q2各产品销售利润",
  "output_mode": "table_and_summary"
}
```

输出：

* 查询编号
* 标题
* 字段定义
* 数据行
* 合计值
* 时间范围
* 币种
* 主体范围
* 指标版本
* 数据更新时间
* 警告

#### `finance_bi_followup`

输入：

```json
{
  "base_query_id": "biq_xxx",
  "instruction": "只看毛利率低于5%的产品"
}
```

必须基于上一轮 `SemanticQuery` 修改，不重新自由生成 SQL。

#### `finance_bi_explain`

用于解释：

* 指标定义
* 查询数据集
* 时间字段
* 币种
* 过滤条件
* 数据更新时间
* 查询依据

#### `finance_bi_catalog_search`

用于查询：

* 可用数据集
* 可用指标
* 可用维度
* 指标别名
* 数据集用途

#### `finance_bi_validate_result`

用于正式报告前检查：

* 指标
* 时间
* 主体
* 币种
* 聚合粒度
* 数据质量警告

#### `finance_bi_export_result`

支持：

```text
csv
xlsx
```

输出目录固定为：

```text
/data/hermes/workspace/exports/bi/
```

### FR-05 SQL 编译和校验

SQL 必须由确定性编译器生成。

使用 SQL AST 校验以下规则：

* 只允许 `SELECT` 和 `WITH`
* 禁止多语句
* 禁止 DDL
* 禁止 DML
* 禁止存储过程
* 禁止未批准 schema
* 禁止未批准表和字段
* 禁止未登记 JOIN
* 必须设置 LIMIT
* 必须设置查询超时
* 必须执行主体权限过滤
* 必须执行字段脱敏

不得向 Hermes 注册以下工具：

```text
execute_sql
run_raw_sql
query_database
```

### FR-07 多轮查询

插件保存：

* `query_id`
* `SemanticQuery`
* 指标版本

* 创建时间

不保存：

* 完整结果集

* 敏感金额

### FR-08 权限

MVP 支持静态实例权限：

```env
FINANCE_BI_ALLOWED_ENTITIES=HK01,SG01
FINANCE_BI_ALLOWED_SCHEMAS=bi_finance,bi_sales
```

所有进入该实例的用户共享同一权限范围。

在没有接入用户身份和动态行级权限前：

* 不允许作为多租户公共服务
* 不允许暴露到公网
* 不允许配置全公司无限制数据库账号

后续由 nodeskclaw 传递已签名用户上下文，再实现用户级动态权限。

审计不得记录：

## 13. 错误码

插件统一返回：

| 错误码                      | 含义         |
| ------------------------ | ---------- |
| `INVALID_ARGUMENT`       | 参数错误       |
| `CATALOG_NOT_READY`      | 语义目录不可用    |
| `METRIC_NOT_FOUND`       | 指标不存在      |
| `DIMENSION_NOT_FOUND`    | 维度不存在      |
| `CLARIFICATION_REQUIRED` | 需要用户确认口径   |
| `QUERY_POLICY_VIOLATION` | 查询违反安全策略   |
| `ACCESS_DENIED`          | 无数据权限      |
| `QUERY_TOO_EXPENSIVE`    | 查询成本过高     |
| `QUERY_TIMEOUT`          | 查询超时       |
| `DATASOURCE_UNAVAILABLE` | 数据源不可用     |
| `QUERY_NOT_FOUND`        | 查询编号不存在或过期 |
| `EXPORT_FAILED`          | 导出失败       |
| `INTERNAL_ERROR`         | 未分类内部错误    |

错误响应不得包含堆栈、密码或完整 DSN。
